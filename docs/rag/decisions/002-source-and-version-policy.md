# ADR 002: 출처를 보존하고 새 버전 준비 후 전환

상태: 첫 구현 선택. 기록일: 2026-11-01.

## 결정

- 첫 출처는 온통청년 API다. API에서 확인된 텍스트를 근거로 사용한다.
- 기존 `noticeText`의 4,000자 제한을 RAG 원본에 적용하지 않는다.
- 원본 JSON과 정리한 본문을 보존한다. 화면용 추정 장소·준비물을 공식 근거에 추가하지 않는다.
- 정리된 본문 및 파이프라인 설정으로 변경을 판별한다. 동일 자료는 재임베딩하지 않는다.
- 새 청크 저장이 성공한 뒤 활성 버전을 교체한다. 실패하면 이전 성공 버전을 유지한다.
- 모델·차원·분할 버전이 바뀌면 같은 본문이라도 새로 색인한다.

## 이유

원문을 남기면 분할 규칙을 바꿀 때 수집부터 반복할 필요가 줄어든다. 활성 버전을 원자적으로 바꾸면 한 답변에서 수정 전·후 조건이 섞이는 것을 방지할 수 있다.

## 후속 범위

공식 HTML·첨부파일을 추가할 때는 출처별 문서와 정책 연도·모집 회차를 관리해야 한다. 같은 URL에 다음 연도 사업이 게시돼도 과거 공고에 그대로 붙이지 않는다. API와 원문이 충돌하면 출처·시점을 표시하고 충돌을 해결한 뒤 답변에 사용한다.
